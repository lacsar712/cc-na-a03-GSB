# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

顶栏「逾期灯」：不合格的灯超过天数门槛仍没有新的合格实测，即进入逾期现表（按灯号归并，只留最近一次仍不合格且超期的实测），并同时写入一条逾期大事记。天数门槛单独保存、改完立即生效；补上合格实测后现表去掉该灯，大事记保留并标已解除。只读账号能看现表和大事记，不能改天数。


## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. keeper 进顶栏「逾期灯」，把天数改成 0 保存：偏暗种子 LH-09 进入逾期现表，大事记多一条（未解除，记下当时门槛 0 和所依实测编号）。
5. 给 LH-09 登记一条合格实测，再回到「逾期灯」：现表不再含 LH-09，大事记那条仍在并显示已解除。
6. watch 登录能看现表和大事记，但页面没有改天数的表单，直接提交也会被拒绝。
